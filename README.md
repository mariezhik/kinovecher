# Киновечер

Прототип веб-сервиса для выбора фильма на вечер.

## Возможности

- Каталог из 10 фильмов с постерами и краткими описаниями.
- Поиск по названию и режиссёру, фильтры по жанру и длительности, сортировка.
- Страница фильма: сюжет, настроение, визуальный стиль, актёры и источники.
- Тёмная тема, адаптивная вёрстка, фон со свечами и тыквами, курсор-свеча.

## Локальный просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите:

- Source: **Deploy from a branch**.
- Branch: **main**, папка **/ (root)**.

Нажмите **Save**. После завершения публикации GitHub покажет ссылку сайта.

## Материалы

Сведения о фильмах взяты из предоставленного набора `movies.json`. Даты проверки рейтингов и ссылки на источники приведены на страницах фильмов. Фоновое изображение сгенерировано с помощью ИИ. Постеры и сведения о фильмах принадлежат их соответствующим правообладателям.
